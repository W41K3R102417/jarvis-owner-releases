# Jarvis Owner app — Changelog

## v0.4.0

Production release of the Jarvis Owner application
(`com.jarvis.mobile.owner`, versionCode 14).

- Owner dashboard: users, devices, audit, all capability-gated
  server-side.
- Verified HTTPS update discovery, download, and cryptographic
  verification with system-installer handoff.
- Installing this app grants no privileges; the Core server remains
  authoritative for every administrative operation.
